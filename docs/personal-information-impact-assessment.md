# 个人信息保护影响评估（工程草案）

版本：2026-09-20。本文是上线前的工程自查材料，不替代专业法律意见。

## 处理目的与必要性

账号信息用于验证用户身份；昵称、签名、头像用于展示个人资料；评论、附件用于社区交流；举报和申诉用于治理；IP 与 User-Agent 的带盐哈希用于会话安全、限流和审计。CAN 分析文件仍默认只在浏览器本地处理。

不收集电脑用户名、身份证号码、精确位置、通讯录、支付信息或生物识别信息。社区规则禁止用户主动上传敏感个人信息和企业机密。

## 数据流与境外接收方

浏览器请求由 Cloudflare 网络处理；账号、评论及治理数据保存到 D1；头像与附件保存到私有 R2；邮件任务经过 Queues 并交给最终确认的事务邮件服务商。Cloudflare 当前不提供中国大陆 D1/R2 数据驻留司法辖区，因此按个人信息境外处理设计。

上线前必须记录 Cloudflare 和邮件服务商的法定名称、联系方式、处理地点、处理目的、数据种类、保存期限、再委托情况和用户权利受理渠道。

## 风险与缓解

| 风险 | 缓解措施 |
|---|---|
| 账号泄露 | PBKDF2 密码哈希、HttpOnly Cookie、限流、会话撤销、邮箱验证 |
| 管理后台失陷 | Access JWT、唯一邮箱、强制 MFA、二次确认、审计记录 |
| 恶意附件 | 类型/大小白名单、私有 Bucket、下载强制 attachment、nosniff、后续接入扫描隔离 |
| 跨境告知不足 | 注册页单独复选框、版本化同意记录、公开隐私政策、重大变化重新同意 |
| 无限保存 | 分类型期限、定时清理、账号注销去身份化、备份到期淘汰 |
| 邮件不可用 | Outbox、Queue、重试、DLQ、后台未读通知；邮件不阻塞评论 |
| 用户内容违法或侵权 | 登录后发言、限流、举报、管理员隐藏/删除、申诉和不可修改审计记录 |

## 初步合规路径

预计处理人数低于十万人，且主动禁止敏感个人信息。在适用《促进和规范数据跨境流动规定》的前提下，可能免于申报安全评估、订立标准合同或认证，但不免除告知、单独同意、最小必要、影响评估、安全保护及个人权利响应义务。上线前由合格专业人士结合运营主体、实际用户规模、供应商合同和数据流复核。
